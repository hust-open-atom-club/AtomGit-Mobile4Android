# 待办页设计稿

与 Compose 实现同步的视觉稿与 token。

## 文件

| 文件 | 说明 |
| --- | --- |
| `TodoScreen.svg` | 390×844 矢量稿（可拖入 Figma） |
| `TodoScreen.html` | 浏览器可预览的同款高保真稿 |
| `design-tokens.json` | 颜色 / 圆角 / 间距 / 组件结构 |

## 导出为 `.fig`

`.fig` 是 Figma 专有二进制，需要桌面版落盘：

1. 安装并打开 [Figma Desktop](https://www.figma.com/downloads/)
2. 新建文件，把 `TodoScreen.svg` 拖进画布
3. **File → Save local copy…** → 保存为 `TodoScreen.fig`
